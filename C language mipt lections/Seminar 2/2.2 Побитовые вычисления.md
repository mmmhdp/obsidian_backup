# Основые побитовые операции в С

x y 
0 0 
0 1 
1 0 
1 1 

| Операция                                 | Название                    | Таблица истинности | Комментарий                                                                                                                                    |
| ---------------------------------------- | --------------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| x & y                                    | коньюнкция                  | 0 0 0 1            |                                                                                                                                                |
| x \| y                                   | дизъюнкция                  | 0 1 1 1            |                                                                                                                                                |
| ~x                                       | отрицание                   | 1 1 0 0            |                                                                                                                                                |
| x ^ y                                    | исключающее или (xor)       | 0 1 1 0            |                                                                                                                                                |
| ~x \| y                                  | импликация (из x следует y) | 1 1 0 1            | Пусть из X => Y, тогда из ~Y => ~X<br>Т.е. истина следует из истины, но также из ложного<br>так как из ложного может следовать всё, что угодно |
| ~(x & y)                                 | штрих Шеффера               | 1 1 1 0            | Истинно только когда, оба операнда истины                                                                                                      |
| ~(x \| y)                                | стрелка Пирса               | 1 0 0 0            | Истинно только тогда, оба операнда ложны                                                                                                       |
| x << n == x * 2^n                        |                             |                    |                                                                                                                                                |
| x >> n == x / 2^n                        |                             |                    |                                                                                                                                                |
| median (x,y,z) = (x\|y) & (y\|z) & (x&z) | тернарная медиана           |                    | по смыслу - это голосование, т.е. 2-е единицы и один ноль дают 0 и т.д                                                                         |
| a^1 == ~a                                |                             |                    |                                                                                                                                                |
| a&0 == a                                 |                             |                    |                                                                                                                                                |
| a^a == 0                                 |                             |                    |                                                                                                                                                |
| a_x = (n>>x) & 1                         | узнать a_x                  |                    |                                                                                                                                                |
| n = n \| (1 << x)                        | установить a_x = 1          |                    |                                                                                                                                                |
| n = n & ~(1 << x)                        | установить a_x = 0          |                    |                                                                                                                                                |
| n = n ^ (1 << x)                         | инвертировать значение a_x  |                    |                                                                                                                                                |
