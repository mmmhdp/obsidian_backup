# Математика по модулю 
Два числа называются равными по модулю m (конгруентными), если m делит их разность.
Иначе говоря, данные числа имеют одинаковый остаток от деления на m, что эквивалентно предыдущему определению.
$$
\begin{align}
a = km + q, b = tm + n \\
a - b  = m (k - t) + (q - n) = Pm + Q \\
Q = q - n \\
\text{Тогда, пусть } q=n  \Rightarrow Q = 0 \Rightarrow a - b = Pm
\end{align}
$$
