# Сортировки с глобальным принятием решений
## Сортировки типа разделяй и властвуй

### Быстрая сортировка
Худший случай - O(n^2), когда pivot - это самый маленький элемент в секции.
Но по памяти - O(1).

На практике в среднем асимптотика O(nlogn), а выделение доп памяти не требуется, 
поэтому о данной сортировке и говорят как о быстрой.
![[qsort.png]]
1) Массив делится на две части по pivot элементу - в одной части все элементы больше или равны pivot, а в другой - меньше чем pivot
2) Далее результаты разбиения сортируются тем же способом.
3) В итоге массив собирается из данных частей.

#### Разделение по pivot элементу
Тут важно предложить вариант с O(1) по памяти с использованием двух указателей.
Левый ищет элемент больше либо равный pivot, правый - меньше pivot, а далее найденный элементы меняются местами.
Как только указатели встретились, мы нашли место, куда должен встать pivot.
Для вставки, мы также обменяем его с (указатель - 1), чтобы обменять с элементом, который меньше его.

### Сортировка слиянием
Данная сортировка имеет стабильную асимптотику O(nlogn)
Но также выделяет O(1) по памяти.

![[Pasted image 20250626091643.png]]
В данном случае, идея близка к qsort, но теперь pivot элемент - всегда элемент по середине.
1) Массив делится на две части (примерно) по pivot элементу.
2) В итоге массив собирается из данных частей.

Т.е. так мы гарантируем logn разбиений.
