# East Const vs West Const 
Дело в том, что в С можно менять порядок слов в cdecl, но при этом получать одинаковый результат, например
```
int const x = 3; (east const) 
const int y = 5; (west const)
//это две одинаковые записи - x и y - это неизменяемые целые
```
В случае east const правило чтения всегда одно - неизменяемый объект находится слева от const.
В случае west const - неизменяеймый объект слева, кроме случаев, когда есть объект справа - тогда константным будет уже он.
(Это общее правило для const вообще)

Некоторые считают, что west const написание читается удобнее - неизменяемое целое, в отличии от east const - целое неизменяемое.
Однако, простив west const существует существенный агрумент от typedefs.
## Критический момент
```
typedef int * PINT;

(east const) PINT const; // <==> int * const
(west const) const PINT; // <==> ТОЖЕ int * const, А НЕ КАК МОГЛО БЫ ПОКАЗАТЬСЯ, ЧТО const int * !!!
```
Т.е. в случае east const - нет двойственности, у нас действительно получится неизменяемый PINT, т.е. неизменяемый УКАЗАТЕЛЬ на целое.
В случае west const - это тоже самое, что может вводить в заблуждение!

Однако, очень многие используют именно west const, порой принципиально.

# Сортировки
## С локальным принятием решений 
В данном случае, на каждой итерации анализируется только один элемент массива в том или ином виде.
Из Master's Theorem следует, что для таких алгоритмов O(кол-во сравнений + кол-во вставок) не менее, чем O(n^2).
### Сортировка выбором
0) Индекс последнего отсортированного элемента = 0
1) Находим минимальный элемент в неотсортированной части
2) Меняем его с элементом, который сейчас на месте с индексом
3) Инкрементируем индекс
4) Повторяем с 1 по 3 пока индекс не станет равен длине массива

### Сортировка вставками
0) Сортируем первые два элемента массива
1) Инициализируем индекс 2
2) Далее последовательно сравниваем элемент с этим индексом с уже отсортированной частью и находим его место
3) Сдвигаем массив и вставляем элемент на его место 
4) Инкремент 
5) Повторять, пока не выставим всё элементы 

## Сортировка пузырьком
Проходим по всему массиву, меняя соседние местами, если их порядок неверен.
Останавливаемся, когда за проход не произошло перемен мест у эелементов.
Псевдокод:
```
do {
	int sw = 0;
	for (j = len - 1; j > 0; j--){
		if (arr[j] < arr[j - 1])
			int tmp = arr[j];
			arr[j] = arr[j - 1];
			arr[j - 1] = tmp;
			sw++;
	}
} 
while (sw == 1)
```
# Поиск
## Бинарный 
Применим в отсортированном массиве!
Асимптотика O(log(n))
Псевдокод:
```
int il = 0, ir = len - 1, imid;

for(;il <= ir;){
	imid = il + (ir - il) / 2;
	if (base[imid] == key)
		return TRUE;
	if (base[imid] < key){
		il = imid + 1;
	}
	if (base[imid] > key){
		ir = imid - 1;	
	}
}

return FALSE;
```
