# <mark class="hltr-coler">Функция распределения случайной величины</mark>
Пусть $\xi$ — случайная величина с распределением:

| $\xi$ | $x_1$ | $x_2$ | $x_3$ | $\dots$ | $x_n$ |
| ----- | ----- | ----- | ----- | ------- | ----- |
| $p_i$ | $p_1$ | $p_2$ | $p_3$ | $\dots$ | $p_n$ |

где $x_1 < x_2 < x_3 < \dots$.
## <mark class="hltr-yellow">Функция распределения</mark>
Определим функцию распределения как:
$$
F_\xi(x) := P(\xi \leq x)
$$
которая называется <mark class="hltr-па">функцией распределения случайной величины</mark>.
## <mark class="hltr-yellow">Свойства функции распределения</mark>
1. $F(-\infty) = 0$, $F(+\infty) = 1$.
2. $F(x)$ — неубывающая функция.
## <mark class="hltr-yellow">График функции распределения</mark>
Функция $F_\xi(x)$ представлена в виде ступенчатой линии, где значения вероятностей $p_i$ соответствуют точкам $x_i$.
