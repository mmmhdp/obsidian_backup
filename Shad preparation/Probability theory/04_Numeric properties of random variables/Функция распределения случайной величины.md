# Функция распределения случайной величины
Пусть $\xi$ — случайная величина с распределением:

| $\xi$ | $x_1$ | $x_2$ | $x_3$ | $\dots$ | $x_n$ |
| ----- | ----- | ----- | ----- | ------- | ----- |
| $p_i$ | $p_1$ | $p_2$ | $p_3$ | $\dots$ | $p_n$ |

где $x_1 < x_2 < x_3 < \dots$.
## Функция распределения
Определим функцию распределения как:
$$
F_\xi(x) := P(\xi \leq x)
$$
которая называется функцией распределения случайной величины.
## Свойства функции распределения
1. $F(-\infty) = 0$, $F(+\infty) = 1$.
2. $F(x)$ — неубывающая функция.
## График функции распределения
Функция $F_\xi(x)$ представлена в виде ступенчатой линии, где значения вероятностей $p_i$ соответствуют точкам $x_i$.
