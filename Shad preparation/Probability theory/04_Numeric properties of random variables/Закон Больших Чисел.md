# <mark class="hltr-coler">Закон больших чисел</mark>
Если $S_n = \sum_{i=1}^n \xi_i$, то:
$$
\frac{S_n}{n} \xrightarrow{n \to \infty} p.
$$

#### Обоснование:
1. $P\left(\left|\frac{S_n}{n} - p\right| \geq \varepsilon\right) \leq \frac{D(S_n/n)}{\varepsilon^2} = \frac{D\xi}{n \varepsilon^2} \to 0 \text{ при } n \to \infty$.
2. $\mathbb{E}\left[\frac{S_n}{n}\right] = p$.

## <mark class="hltr-yellow">Заключение</mark>
Для последовательности независимых Бернуллиевских случайных величин закон больших чисел выполняется.
