# <mark class="hltr-coler">Cходимость по вероятности</mark>
Сходимость для случая частоты - это не тривиальный вопрос, так как $S_n$ - это множество функций, т.е.
в данном случае рассматривается сходимость над пространством функций.
Далее определим данную сходимость через уже известную сходимость последовательности, рассматривая вероятность.
Данное определение сходимость - сходимость по веротности.

Для любого $\varepsilon > 0$:
$$
P\left(\left|\frac{S_n}{n} - p\right| > \varepsilon\right) \to 0 \quad \text{при } n \to \infty
$$
Или, эквивалентно (<mark class="hltr-yellow">сходимость по вероятности</mark>):
$$
P\left(\left|\frac{S_n}{n} - p\right| < \varepsilon\right) \to 1 \quad \text{при } n \to \infty.
$$
