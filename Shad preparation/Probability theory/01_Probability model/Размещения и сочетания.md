# <mark class="hltr-coler">Размещения с повторениями</mark>
Составляем упорядоченный набор длины $k$ из $n$ элементов с возвращением.
$$
\Omega = \{ (a_1, \ldots, a_k) \}, a_i = \overline{1,\ldots,n}
$$
$$
|\Omega| = n^k
$$
## <mark class="hltr-yellow">Интерпретация</mark>
Все слова длины $k$ в алфавите из $n$ букв.
# <mark class="hltr-coler">Размещения без повторений</mark>
Составляем упорядоченный набор длины $k$ из $n$ элементов без возвращения.
$$
\Omega = \{ (a_1, \ldots, a_k) \}, \text{где все } a_i - \text{различны}
$$
$$
|\Omega| = \frac{n!}{(n-k)!}
$$
## <mark class="hltr-yellow">Интерпретация</mark>
Все слова длины $k$ в алфавите из $n$ букв, но каждую букву можно использовать только один раз.

# <mark class="hltr-coler">Сочетания без повторений</mark>
Неупорядоченный набор размера $k$ из $b$ элементов без возвращения.
$$
\Omega = \{ \{a_1, \ldots, a_k \} \}, \text{где все } a_i - \text{различны}
$$
$$
|\Omega| = C_n^k = \frac{n!}{(n-k)!k!}
$$
## <mark class="hltr-yellow">Интерпретация</mark>
- Последовательности длины $n$ из 0 и 1, в которых ровно $k$ единиц.

# <mark class="hltr-coler">Сочетания с повторениями</mark>
Неупорядоченный набор размера $k$ из $n$ элементов с возвращения.
$$
\Omega = \{ (a_1, \ldots, a_k) \}, a_i = \overline{1,\ldots,n}
$$
$$
|\Omega| = C_{n+k-1}^{n-1} = C_{n+k-1}^{k}
$$
## <mark class="hltr-yellow">Интерпретация</mark>
- Разложим в $n$ ящиков $k$ неразличимых шаров, в одном ящике может быть сколько угодно шаров, хоть ноль. 
  Тогда $a_i$ - это номер ящика, куда мы положили $i$-ый шар.
  А далее перевёдем это в вид вектора, где разделением будет 1, а 0 - это шарики:
  001010
  Это 2 шара в первом, один во 2 и одни в 3.
  Тогда ясно, что таких комбинаций столькоже, сколько способов расставить
  единички по любым местам или тоже для нулей, т.е. получаем уже модель знакомую - сочетания без повторений.
