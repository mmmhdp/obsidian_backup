Данные модификаторы метода позволяют ему получить доступ к 
приватному состоянию класса.

Важно, что в такие функции НЕ передаётся `this` первых аргументом `implicitely`, а надо его передавать руками, если он там нужен.
```cpp
class S {
	int x_ = 0;
public: 
	int get_x() const {return x_;}
	static int s_get_x (S *s) {return s->x_}
	friend int f_get_x (S *s);
};


f_get_x (S *s) {
	return s->x_;
}
```
# Диаграмма возможностей
||методы|статические функции|друзья|
|-|-|-|-|
|получает неявный указатель на this|да|нет|нет|
|находится в пространстве имён класса|да|да|нет|
|имеет доступ к закрытому состоянию класса|да|да|да|

# Дружба это магия
- Статические функции более безопасны. Они являются частью интерфейса класса и пишет их разрабочик, который заботится о сохранении инвариантов
- Функции-друзья обычно пишет кто-то другой и они могут эти самые инварианты наоборот нарушать как хотят
- Особенно опасно - дружить с целыми классами
- В целом дружба часто связана с магией и заводя себе друзей вы скорее всего совершаете ошибку
# `Use cases`
## Конструкторы
```cpp
template <typename T> class Matrix {
	// некое представление
public:
	// конструктор для создания матрицы, заполненной значением
	Matrix (int cols, int rows, T val = T{});
	
	// конструктор для создания матрицы из заданной последовательности
	template <typename it>
	Matrix (int cols, int rows, It start, It fin);
	
	// конструктор для создания единичной матрицы
	Matrix eye(int n, int m);
};
```
