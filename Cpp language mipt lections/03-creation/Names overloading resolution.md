Примерный набор действий компилятора для разрешения перегузки в первом приближении выглядит так:
- Изначально составляется список кандидатов с данным именем.
На данном этапе сформирован так называемы **overloading set**.
- Далее фильтруются "дикие" кандидаты - например, несовпадает кол-во агрументов.
На данном этапе список этих потенциальных кандидатов называется **viable candidates**.

А после идут критерии сортировки уже для вот этих вот кандидатов в данном порядке(указаны не все):
1. Точное совпадение (`int -> int`, `int -> const int &`, etc)
2. Точное совпадение с шаблоном (`int -> T`) 
  Тут есть камни, про них в секции о шаблонах
3. Стандартные преобразования (`int -> char`, `float -> unsigned short`, etc)
4. Совпадение с пользовательскими преобразованиями
5. Переменное число аргументов (`VA_ARGS`)
6. Неправильно связанные ссылки (`literal -> int&`, etc)
