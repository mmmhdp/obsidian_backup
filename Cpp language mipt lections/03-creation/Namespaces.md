# Правила хорошего тона
- Не засорять глобальное пространство имён
- Никогда не писать using namespace в заголовочных файлах
- Использовать анонимные пространства имён вместо статических фунций для инкапсуляции в модуле 
- Не использовать анонимные пространства имён в заголовоных файлах
