Вообще говоря, при создании пустого класса, сам класс таковым не является.

С одной стороны, если ли у него нет виртуальных методов и множественного наследования, он будет занимать `1` байт. Обусловлено это тем, что размер необходим для создания массива таких объектов через оператор `new` и дальнейшая возможность удалить данные объекты.  

С другой, дело в том, что за пользователя языка для такого класса по дефолту объявлен ещё и целый ряд методов.
```cpp
class Emply {

};
```
Но надев "волшебные очки" мы вдруг обнаружим, что мы можем:
```cpp
{
	Empty x; // Создать объект такого класса
	Empty y (x); // Скопировать
	x = y; // Присвоить
}
// А тут ещё и деструктор будет вызван у каждого из объектов
```
Собственно, на самом деле класс выглядит так:
```cpp

//class Emply {
Empty(); // ctor
~Empty(); // dtor
Empty(const Empty& rhs); // copy ctor
Empty& operator=(const Empty& rhs); // assigment operator
Empty(Empty&& rhs) {}; // move ctor
Empty& operator=(Empty&& rhs) // move assignment operator
//};
```
