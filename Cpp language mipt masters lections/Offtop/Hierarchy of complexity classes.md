| Complexity Class                          | What it means                                                                             | Example Problem                                                                                                                              |
| ----------------------------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **L (Logarithmic Space)**                 | Solved using only **O(log n)** memory. Very little working memory is allowed.             | **Is there a path in a linked list from node A to node B?** (following pointers one at a time)                                               |
| **NL (Nondeterministic Log Space)**       | Solved using **O(log n)** memory with nondeterministic guessing.                          | **Graph Reachability:** Is there a path from node **s** to node **t** in a directed graph?                                                   |
| **P (Polynomial Time)**                   | Solved in polynomial time, such as (n), (n^2), or (n^3). Considered efficiently solvable. | **Sorting** numbers, **finding the shortest path** (Dijkstra's algorithm).                                                                   |
| **NP (Nondeterministic Polynomial Time)** | A proposed solution can be **verified** in polynomial time.                               | **Sudoku:** Given a completed Sudoku board, checking that it is valid is fast. Finding the solution is believed to be hard.                  |
| **PSPACE (Polynomial Space)**             | Solved using polynomial memory, even if it takes exponential time.                        | **Generalized Chess:** Can the first player force a win? The algorithm may explore many moves but only needs to remember one path at a time. |
| **EXPTIME (Exponential Time)**            | Requires exponential time in the worst case.                                              | Solving certain generalized board games by examining an exponentially large game tree.                                                       |
| **EXPSPACE (Exponential Space)**          | Requires exponential memory. This is even more powerful than EXPTIME.                     | Artificial problems that need storing an exponentially large table during computation.                                                       |
